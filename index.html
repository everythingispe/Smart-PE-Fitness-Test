ระบบบริหารจัดการข้อมูลสมรรถภาพทางกาย

บันทึกผลทดสอบ

ค้นหาประวัติ

ส่วนงาน Admin / รายงาน

1. ค้นหาข้อมูลเพื่อบันทึก/แก้ไข
2. ข้อมูลนักเรียน (ดึงจากฐานข้อมูลทะเบียน)
3. ผลการทดสอบสมรรถภาพ
ตัวกรองข้อมูลรายห้องและระดับชั้น
เลือกรหัสนักเรียนชั้น/ห้องเลขที่ชื่อ-สกุล BMIงอตัวยกเข่าดันพื้นลุกนั่ง ภาคเรียนปีการศึกษาคะแนนรวมRankจัดการ
กรุณาเลือกตัวกรองด้านบน แล้วกดปุ่ม "แสดงข้อมูล" เพื่อเรียกดูบัญชีรายชื่อ
รายการนักเรียนค้างทดสอบ: เปรียบเทียบจากทะเบียนนักเรียน (Student_DB) ที่ยังไม่มีผลการทดสอบในเทอม/ปีการศึกษาที่ระบุ
ลำดับรหัสนักเรียนชั้น/ห้องเลขที่ชื่อ-นามสกุล ภาคเรียนปีการศึกษาสถานะการทดสอบดำเนินการ
กรุณาเลือกตัวกรองด้านบนเป็นตัวเลข (ภาคเรียน, ปีการศึกษา, ระดับชั้น) แล้วกดปุ่ม "แสดงข้อมูล"
สรุปแผนภูมิสถิติและเกณฑ์การประเมินสมรรถภาพ
ตารางจำแนกจำนวนและเปอร์เซ็นต์ตามระดับเกณฑ์ (5 รายการประเมิน)
รายการประเมิน ต่ำมาก / ผอมมาก ต่ำ / ผอม ปานกลาง / สมส่วน ดี / ท้วม ดีมาก / อ้วน รวม (คน)
